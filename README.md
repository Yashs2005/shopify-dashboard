# 🛒 Shopify Admin Dashboard

A modern and responsive Shopify-style Admin Dashboard and Customer Shopping Platform built using React.js.

## 🚀 Live Demo

https://shopify-dashboard-two-theta.vercel.app

## ✨ Features

### 👨‍💼 Admin Dashboard
- Dashboard overview
- Product management
- Order management
- Customer management
- Analytics dashboard
- Sales reports
- Low stock alerts
- Search and filtering
- Dark mode

### 🛍️ Customer Shopping
- Customer View
- Product search
- Product details
- Product quantity selection
- Add to Cart
- Buy Now
- Shopping Cart
- Checkout
- Order placement
- Order status tracking

### 📊 Analytics
- Total sales
- Monthly revenue
- Total orders
- Top products
- Average order value
- Revenue chart
- Orders trend
- Product sales distribution
- Monthly sales report
- CSV report export

### 📱 Responsive Design
- Desktop responsive
- Mobile responsive
- Tablet friendly
- Mobile shopping experience
